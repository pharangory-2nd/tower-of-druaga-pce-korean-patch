# PC엔진 드루아가의 탑 한글패치

일본판 HuCard 『드루아가의 탑』의 한글패치입니다. 프롤로그, 여신 힌트, 아이템 이름, 메뉴, 능력치 화면과 엔딩을 한글로 즐길 수 있습니다.

**[최신 버전 다운로드 및 설치 안내](https://github.com/pharangory-2nd/tower-of-druaga-pce-korean-patch/releases/latest)**

Windows에서는 릴리스의 패치 ZIP을 풀고 `Apply-Korean.exe`를 실행한 뒤 보유한 일본판 원본 ROM을 선택하세요. 다른 환경에서는 동봉된 BPS 패치를 사용할 수 있습니다.

RetroArch의 Beetle PCE 코어에서 구동을 확인했습니다. PC엔진 실기·EverDrive와 SuperStation One에서의 구동은 미확인입니다.

번역·패치·글꼴을 재사용할 때의 조건은 [구성요소별 라이선스](LICENSE.md)에서 확인할 수 있습니다.

## 제작 과정

이 한글패치의 ROM 분석, 번역 초안 작성, 한글 글꼴과 패치 코드 제작, 화면 검증에 OpenAI Codex를 활용했습니다. 최종 번역 검수와 RetroArch 플레이 확인은 제작자 까치의 꿈이 직접 진행했습니다.
